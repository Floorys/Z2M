# Если не работает

## nfqws2: Segmentation fault

Симптом: `z2m doctor` пишет, что бинарь не запускается, в логах падение.

Часть сборок под `aarch64_cortex-a53` и `aarch64_generic` была нерабочей.
Решение: `z2m pick` и взять соседнюю версию релиза. Если помогло — запишите
связку "архитектура + версия" в `docs/COMPAT.md` и пришлите PR.

## Стратегия применилась, но демон не поднялся

Почти всегда синтаксис строки `NFQWS2_OPT`. Посмотрите:

```
logread -e nfqws2 | tail -n 20
```

Вернуться назад: `z2m restore` — бэкап делается перед каждым изменением.

## Всё запущено, но блокировки остались

1. **Flow offloading.** Аппаратное или программное ускорение уводит пакеты мимо
   nfqueue. `z2m doctor` предупреждает; выключается в Network → Firewall.
2. **DNS.** Без DoH/DoT часть ресурсов режется на уровне имён, и никакой
   anti-DPI не поможет.
3. **QUIC.** Браузер мог уйти на UDP/443, где стратегия не работает.
   Временно: `z2m quic on` — браузеры откатятся на TCP.
4. **IPv6.** Если у провайдера есть IPv6, трафик может идти по нему:
   `z2m ipv6 on` включает обработку IPv6 в zapret2.
5. **Кэш браузера и соединения.** После смены стратегии закройте вкладки или
   перезапустите браузер.

## zapret v1 и zapret2 вместе

Не работают: оба вешаются на nfqueue. Сначала удалите первый:

```
/etc/init.d/zapret stop
/etc/init.d/zapret disable
opkg remove luci-app-zapret zapret
```

## Где что лежит

| Путь | Что |
| --- | --- |
| `/opt/zapret2` | сам zapret2 |
| `/opt/zapret2/nfq2/nfqws2` | демон |
| `/opt/zapret2/blockcheck2.sh` | штатный подборщик |
| `/etc/config/zapret2` | конфиг пакета remittor (UCI) |
| `/opt/zapret2/config` | конфиг апстримной установки |
| `/etc/z2m/` | всё своё: пресеты, наборы, бэкапы, лог |
